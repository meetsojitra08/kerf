# Design review
Run `/ui-review`. Reject if: purple/blue gradient surfaces, sparkle/magic-wand icons for AI, glass blur panels, uniform 12px-radius card grids, centered empty-state chat box, default Inter + gray-900 look, decorative shadows, emoji as UI. Prefer: dense tool-like layouts, hairline rules, tabular numerals for timecode, one accent color used sparingly, motion that explains cause and effect.
